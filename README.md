# The Moon Finally Answers Back

One line the Moon says back to everyone who ever stared up at it, for make.fun's `u-mang-the-moon-finally-answers-back-781a7ec1` bounty.

The line: *"You keep howling at me like I did something. I only reflect sunlight — take it up with the Sun, he's the one with the ego."* (122 characters)

The field is four billion years of wishes, tides, read receipts, and the Moon drifting away at 3.8 centimetres a year. This one gives the Moon a different move: it deflects the blame to the Sun — true (it only reflects sunlight), petty, and a comeback in one read. "He's the one with the ego" is the Moon talking like a tired colleague, not a monument.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`, deterministically.
